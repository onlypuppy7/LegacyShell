# Getting Started

> **Audience:** Total newbies - you don't need to know what a terminal is yet · **Prereqs:** None

This section gets you from "never heard of LegacyShell" to a running local server with your own admin account. It assumes nothing about your technical background.

## What's here

- **[What is LegacyShell?](./what-is-legacyshell.md)** - the three servers explained without jargon, and what you actually need to run.
- **[Speed Setup](./speed-setup.md)** - already comfortable with Node/git? Four commands, no hand-holding, with links out to the detailed pages if something doesn't go as expected.
- **[Requirements](./requirements.md)** - Node versions known to work, git, disk space, OS notes.
- **[Installation](./installation.md)** - clone, `npm install`, `npm run init`, annotated step by step.
- **[First run](./first-run.md)** - `npm run all`, what each window means, opening `localhost:13370`.
- **[Config files](./config-files.md)** - where settings live and how defaults layer under your own overrides.
- **[Making an account](./making-an-account.md)** - registering in-game, then granting yourself admin (bridges into database editing).
- **[Troubleshooting](./troubleshooting.md)** - the specific errors people actually hit (native build failures, ports in use, blank page, forgetting `npm run init`).

If you get through this section, move on to [Running a Server](../02-Running%20a%20Server/) to actually operate an instance, or [Content Creation](../03-Content%20Creation/) if you just want to make maps/models/skins.
